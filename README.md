# metalmind-android

App de Android para **capturar notas rápido** en un vault de [Metalmind](https://github.com/alex-glez-felix/metalmind).

No sincroniza nada por su cuenta: escribe cada captura como un archivo `.md` nuevo en la carpeta del vault, y la sincronización la hace la herramienta que ya uses (Syncthing, git). Sin tags, la nota cae al buzón.

Estado: esqueleto.
